ПАЛАТА 13 — хоррор для Roblox Studio
=====================================

ЧТО ВНУТРИ
- Palata13_Lobby.rbxlx — стартовый плейс: криповое главное меню (тёмный коридор, мигающий фонарик, Пациент 13 приближается рывками),
  зал ожидания с 3 вратами-телепортами (очередь до 4 игроков, отсчёт 20 сек), магазин «Торговец без лица», доска батлпасса.
- Palata13_Game.rbxlx — плейс с картой: заброшенная больница (78 комнат, 108 дверей, 13 тематических зон, двор с воротами выхода),
  монстр с ИИ (патруль, слух, погоня), анимации ходьбы и бега, шаги, дыхание, скример, предохранители, генератор, шкафчики.
- Sounds/ — 20 собственных звуков (.ogg), сгенерированы с нуля: фонарик вкл/выкл, шаги и дыхание монстра, крик, погоня, эмбиент, музыка меню и т.д.
- src/ — все скрипты в виде .lua (для справки или Rojo).

УПРАВЛЕНИЕ
- F — фонарик (батарея садится, батарейки лежат на карте)
- Left Shift — бег
- E — взаимодействие (магазин, батлпасс, шкафчики, предметы)

КАК ЗАПУСТИТЬ (по шагам)
1. Открой Palata13_Lobby.rbxlx в Roblox Studio -> File -> Publish to Roblox -> создай новую игру. Это стартовый плейс.
2. В Studio: View -> Asset Manager -> Places -> правый клик -> Add New Place. Открой этот новый плейс,
   затем открой Palata13_Game.rbxlx и опубликуй его в этот плейс (File -> Publish to Roblox As -> твоя игра -> новый плейс).
3. Узнай ID обоих плейсов (Creator Hub -> игра -> Places).
4. В ОБОИХ плейсах открой ReplicatedStorage -> Shared -> Config и впиши:
   Config.LobbyPlaceId = ID лобби
   Config.GamePlaceId  = ID больницы
5. Home -> Game Settings -> Security -> включи «Enable Studio Access to API Services» (нужно для сохранений: монеты, батлпасс, покупки).
6. Опубликуй оба плейса ещё раз.

ЗВУКИ
1. Creator Hub -> Creations -> Development Items -> Audio -> загрузи все .ogg из папки Sounds (или Asset Manager -> Bulk Import).
2. Скопируй ID каждого звука в Config.Sounds (в обоих плейсах), например: FlashlightOn = 1234567890.
   Пока ID = 0, звук просто не играет — игра не ломается.

МАГАЗИН ЗА РОБУКСЫ
Creator Hub -> игра -> Monetization:
- Passes (покупаются 1 раз): PremiumPass (премиум-дорожка батлпасса), VIP (x2 монет), BigBattery (фонарик дольше и ярче).
- Developer Products (можно много раз): Coins100, Coins500, Coins1500, SkipTier (+1 уровень батлпасса), Revive (возрождение).
Вставь ID в Config.GamePasses и Config.Products. Цены подтягиваются из Roblox автоматически.

БАТЛПАСС
- Опыт дают раунды: собранные предохранители, побег, выживание.
- Бесплатная и премиум-дорожки с наградами: монеты, скины фонарика, титулы, жетоны возрождения.
- Награды забираются у доски объявлений в лобби (клавиша E).

ВАЖНО
- Телепорт между плейсами работает только в опубликованной игре (в Roblox-клиенте), в Studio — нет.
- Больницу можно открыть отдельно и нажать Play, чтобы посмотреть карту и монстра.
- Монстр собран из сотен деталей (тонкие конечности, рёбра, длинные пальцы, разорванная челюсть) с анимацией через Motor6D.
  Если захочешь ещё реалистичнее — замени модель в ServerStorage.Monster на свой MeshPart-риг с теми же именами частей.
